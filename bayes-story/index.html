Chapitre 1

Bayes: le détective des probabilités

Imagine un détective. L’image x est l’indice, et chaque classe k est un suspect. Bayes demande: quelle classe rend cet indice le plus plausible ?

  • P(y = k): l’a priori, ce qu’on croit avant de voir l’image.
  • P(x | y = k): la vraisemblance, ce qu’on observe si la classe k est vraie.
  • P(x): la preuve totale, identique pour toutes les classes, donc on la compare rarement directement.
Idée utile
score(k) = P(x | y = k) × P(y = k)

On compare les scores, puis on garde la classe qui gagne.

Chapitre 2

Le monde gaussien: chaque classe devient un nuage

L’idée forte du statistical learning ici est simple: les points d’une même classe se ressemblent. On les résume avec une moyenne μ et une covariance Σ.

La moyenne dit où le nuage est centré. La covariance dit comment il s’étale, s’incline et se déforme.

Chapitre 3

La frontière: là où deux classes sont à égalité

Une frontière de décision est l’endroit où les scores de deux classes deviennent égaux. Dès que le score de A dépasse celui de B, on bascule de l’autre côté.

classe A classe B
Règle
Choisir la classe avec le score le plus élevé

Le discriminant sert donc à comparer des scores et à dessiner une séparation aussi juste que possible.

Chapitre 4

Le cœur du sujet: pourquoi LDA et QDA existent ?

LDA: même forme pour toutes les classes

  • On suppose que toutes les classes partagent la même covariance Σ.
  • Les termes quadratiques s’annulent dans le discriminant.
  • La frontière devient linéaire: droite, hyperplan, séparation simple.
  • Avantage: robuste, stable, efficace quand les données sont limitées.

Ce que ça change

LDA: g_k(x) = x^TΣ^-1μ_k - 1/2 μ_k^TΣ^-1μ_k + log π_k
Une seule géométrie pour tous les nuages.

LDA coupe l’espace avec une ligne simple parce qu’elle impose la même géométrie pour toutes les classes.

Chapitre 5

Où se placent les autres méthodes ?

Naive Bayes

Très proche de Bayes, mais on suppose souvent l’indépendance entre variables.

LDA

Bayes + gaussiennes + même covariance. Version linéaire, compacte et interprétable.

QDA

Bayes + gaussiennes + covariance différente par classe. Plus flexible, plus coûteux.

Logistic Regression

Apprend directement une frontière sans modéliser la distribution de x.

SVM

Cherche la marge la plus large entre les classes, parfois avec noyaux.

PCA

Réduit la dimension sans utiliser les labels. Utile, mais ce n’est pas un classifieur.

Synthèse

Le fil logique à retenir

  1. Bayes compare des probabilités conditionnelles pour choisir une classe.
  2. Si chaque classe est modélisée comme une gaussienne, on obtient un cadre interprétable.
  3. Si les covariances sont partagées, la frontière est linéaire: c’est LDA.
  4. Si les covariances diffèrent selon la classe, la frontière devient quadratique: c’est QDA.
  5. Les autres méthodes se positionnent autour de cette idée: modéliser la distribution ou apprendre la frontière directement.
